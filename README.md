# 2D射擊遊戲

一個使用Phaser 3開發的完整2D俯視角射擊遊戲，具有多個敵人類型、武器系統、關卡進度、積分系統、成就系統和完整的中文UI界面。

## 🎮 功能特性

### 核心遊戲機制
- ✅ 俯視角射擊遊戲玩法
- ✅ 平滑的玩家控制和移動
- ✅ 敵人AI系統
- ✅ 多種敵人類型（普通、快速、坦克、射手）
- ✅ Boss戰鬥（每5關出現一次）
- ✅ 碰撞檢測和物理系統
- ✅ 多個關卡，難度逐漸遞增
- ✅ 血量系統和護盾系統
- ✅ 無敵段時間機制

### 武器系統
- 🔫 **基礎槍** - 標準單發射擊
- 🔫 **散彈槍** - 多向度射擊，傷害較低
- 🔫 **雷射槍** - 高傷害但射速較慢
- 🔫 **連發槍** - 快速射擊，低傷害
- 🎯 按E鍵切換武器（需要先解鎖）

### 道具系統
- ❤️ **生命值道具** - 回復20點血量
- ⚡ **武器升級** - 解鎖下一個武器
- ⚙️ **速度增強** - 增加移動速度
- 🛡️ **護盾道具** - 增加護盾值

### 視覺和音效
- 🎨 粒子爆炸效果
- 🎨 傷害浮動文本
- 🎨 治療浮動文本
- 🔊 射擊音效
- 🔊 爆炸音效
- 🔊 升級音效
- 🔊 遊戲結束音效

### UI系統
- 📊 實時分數顯示
- 📊 關卡顯示
- 📊 血量條
- 📊 護盾條
- 📊 敵人計數
- 📊 當前武器顯示
- 📊 難度顯示
- 📊 暫停狀態提示

### 難度系統
- 🟢 **簡單** - 敵人速度-30%，傷害-30%
- 🟡 **普通** - 原始難度
- 🔴 **困難** - 敵人速度+50%，傷害+50%
- 💀 **夢魘** - 敵人速度x2，傷害x2

### 成就系統
- 🏆 初試啼聲 - 擊敗10個敵人
- 🏆 怪物獵人 - 擊敗100個敵人
- 🏆 高分達成 - 獲得10000分
- 🏆 倖存者 - 完成第5關
- 🏆 Boss獵人 - 擊敗一個Boss
- 🏆 武器大師 - 解鎖所有武器
- 🏆 完美戰士 - 不受傷害完成一關
- 🏆 幸運兒 - 收集5個道具

### 遊戲系統
- 💾 本地存檔（localStorage）
- 📈 排行榜（歷史最高分）
- ⏸️ 暫停功能（按P鍵）
- 🎵 音效開關控制
- 🎨 設置菜單

## 🚀 安裝和運行

### 前置要求
- Node.js (v14或更高版本)
- npm 或 yarn

### 安裝依賴

```bash
npm install
```

### 開發模式

```bash
npm run dev
```

然後在瀏覽器中打開 `http://localhost:8080`

### 構建生產版本

```bash
npm run build
```

## 🎮 遊戲控制

| 操作 | 按鍵 |
|------|------|
| 移動 | 方向鍵 或 WASD |
| 射擊 | 鼠標點擊 或 空格鍵 |
| 切換武器 | E鍵 |
| 暫停/繼續 | P鍵 |
| 開始遊戲 | SPACE |
| 查看成就 | A |
| 打開設置 | S |
| 返回菜單 | ESC |

## 🎯 遊戲玩法

1. **開始遊戲**
   - 在菜單中選擇難度
   - 難度會影響敵人速度和傷害

2. **戰鬥**
   - 使用方向鍵或WASD移動
   - 用鼠標或空格鍵射擊敵人
   - 收集掉落的道具來恢復血量或升級武器

3. **進度**
   - 擊敗一定數量的敵人後進入下一關
   - 每升一關，敵人會變得更強
   - 每5關會出現一個強大的Boss

4. **結束**
   - 當血量降到0時遊戲結束
   - 查看最終分數和統計數據
   - 成績將被保存到排行榜
